**具体设计**：

| 周              | 数据量        | 设计意图                           |
| -------------- | ---------- | ------------------------------ |
| 本周（8/17-8/23）  | 28 条       | 同原设计（5 天有数据，偏科+物理低分反推教学环境）     |
| 上周（8/10-8/16）  | 25 条       | 6 天有数据，总时长略低，自主比例略低 → 对比本周进步明显 |

**每一周都有**：

* 物理持续低分（近几周有轻微改善）

### B. UI 改造（匹配功能落地优先级表）

#### B1. 学习总时长统计（最高优）：强化"自定义时间范围 + 区分周中周末"

**文件**：`WeekReviewDashboard.jsx` + `DimensionStrip.jsx`

改动：

1. **时间选择器加"自定义"按钮** — 点击弹出两个 `<input type="date">`（起始/结束），选定后应用 customRange
2. **DimensionStrip 总时长卡片增强** — 从一行文字 → 改为两行小数据：

   * 上：周中日均 X min（加进度条）

   * 下：周末日均 Y min（加进度条）

   * 颜色对比更明显（工作日蓝色，周末紫色）

#### B2. 学科时间分配（最高优）：新增"作业顺序偏好"

**文件**：`DeepDivePanels.jsx`（SubjectAllocationPanel 旁新增一个子图）

新增 **SubjectOrderPreferenceChart**：

* 按 `session_date` + `start_time`（空值默认 18:00）把每门课在时间轴上排列

* 横轴是小时（16:00-23:00，覆盖常见作业时间）

* 纵轴是 5 个工作日（周一到周五）

* 每个单元格是一个色块，颜色=科目，宽度=时长比例

* 下方结论：

  * "作业偏好在日落后开始，先做数学再做英语 → 把最难的科放在精力好的时段 ✓"

  * 或 "先花 2h 在数学，最后深夜才做物理 → 薄弱科放在低谷时段 ⚠"

#### B3. 复习时长统计（高优）：区分自主/非自主复习 + 按学科展示

**文件**：`DeepDivePanels.jsx`（CategoryCyclePanel 旁新增一个面板，或把 SubjectAllocationPanel 升级）

把现有 **SubjectAllocationPanel** 升级为三栏堆叠进度条：

* **每门课一行**，每行分为三部分：\[ 学习 | 复习 | 练习 ]

* 复习部分再分两色：深色=自主复习，浅色=外部复习（辅导班/老师安排）

* 每行右侧显示：总时长 + 复习占比% + 复习中自主占比%

* 高风险高亮：某门课复习占比<10% 或复习中自主占比<30% → 橙色/红色背景提示

这样同时覆盖了"按学科单独展示"和"区分自主/非自主复习"两个要求。

#### B4. 练习质量与反馈（中优）：客观反馈密度监控 + 风险提示联动

**文件**：`DeepDivePanels.jsx`

在 PracticeQualityPanel 下方增加 **FeedbackRiskRow**：

* 每门课一行：科目名 | 练习次数 | 有反馈次数 | 反馈密度% | 风险标签

* 反馈密度% < 40%：显示 🟡 "反馈不足 — 建议记录每题得分"

* 反馈密度% < 20% 且练习次数 ≥ 3：显示 🔴 "高风险 — 大量练习无评估"

* 与诊断规则联动：新增一个 diagnosis rule "某科反馈密度极低"，进入诊断结论面板

## 四、依赖与风险

| 风险                                        | 缓解                                                     |
| ----------------------------------------- | ------------------------------------------------------ |
| 作业顺序偏好需要 `start_time`，老数据可能为 null         | 默认 18:00 + 按 `form` 推断（学校课堂=15:00，校外线上=19:00，自主=18:00） |
| 4 周数据使自主学习趋势折线有意义（否则只有 1 个点）              | 确认 SelfLearningTrendPanel 在 weeks.length>=2 时正确显示      |
| 自定义日期需要两个 `<input type="date">`，移动端可能显示不佳 | 加 CSS 限制宽度，移动端单行换两行                                    |
| SQL 脚本执行时 test 学生 ID 冲突                   | 脚本用 `ON CONFLICT` + 先 DELETE 旧 sessions，保持幂等           |
