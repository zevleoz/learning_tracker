# 导师端修改学生学校名称功能规划

## 问题背景

当前课程共享机制依赖学生注册时填写的 `school_name` 字段。但由于学生可能用不同方式填写学校名称（如："南京一中"、"南京市第一中学"、"Nanjing No.1 Middle School"），导致同一学校的学生无法看到彼此的课程。

## 当前机制分析

### 课程共享逻辑

在 [Syllabus.jsx](file:///Users/jefflau/projects/一表人才/src/pages/Syllabus.jsx) 中：

* 第25-29行：通过 `profiles.school` 获取用户学校名称

* 第31-38行：查询所有课程（未删除的）

* 第42行：通过 `created_by === user.id` 判断是否为自己的课程

* 第197-198行：`myCourses` 和 `sharedCourses` 分离

**问题**：当前课程查询没有按学校过滤，所有课程都被加载。实际上课程共享的前提是学校名称完全匹配。

### 学生列表显示

在 [Mentor.jsx](file:///Users/jefflau/projects/一表人才/src/pages/Mentor.jsx) 中：

* 第99行：收集所有学生的学校名称

* 第364-373行：学校筛选下拉框

* 学生列表中没有显示学校名称

## 功能规划

### 修改点

#### 1. 导师端学生列表 - 添加学校列和编辑功能

**文件**：`src/pages/Mentor.jsx`

在学生列表中：

* 添加"学校"列显示学生当前学校名称

* 添加编辑学校名称的按钮

* 点击编辑后弹出输入框，允许修改学校名称

* 修改后同步更新 `profiles` 表的 `school_name` 字段

#### 2. 导师端学生列表（移动端）

**文件**：`src/pages/Mentor.jsx`

在移动端的 `StudentRow` 组件中：

* 显示学校名称

* 添加编辑学校的交互

#### 3. 数据库权限检查

**文件**：`supabase/schema.patch-check-policies.sql`

确保导师端有修改学生 `school_name` 的权限。

### 实现步骤

1. **在学生列表中显示学校名称**

   * 桌面端：在学生表格中添加"学校"列（第391行附近）

   * 移动端：在 `StudentRow` 组件中添加学校信息显示（第769行附近）

2. **添加编辑学校名称功能**

   * 桌面端：在操作列添加编辑学校按钮

   * 移动端：在 `StudentRow` 中添加编辑按钮

   * 点击后显示输入框和保存/取消按钮

   * 调用 Supabase API 更新 `profiles` 表

3. **添加学校名称自动补全**

   * 收集所有已存在的学校名称

   * 在编辑时提供下拉建议，减少输入错误

4. **更新课程共享查询逻辑（可选优化）**

   * 当前逻辑：查询所有课程，前端过滤

   * 优化方案：按学校名称过滤查询，减少数据传输

### 风险与注意事项

1. **数据一致性**

   * 修改学校名称后，学生重新登录才能看到新的共享课程

   * 需要通知学生学校名称已被修改

2. **权限控制**

   * 确保只有导师（role >= 2）才能修改学生学校名称

   * 需要检查 RLS 策略是否允许修改其他用户的 profile

3. **学校名称规范化**

   * 建议导师使用统一的学校名称格式

   * 可添加常用学校名称列表供选择

4. **课程数据关联**

   * 修改学校名称不会影响学生已创建的课程

   * 课程的 `source` 或 `created_by` 保持不变

### 测试计划

1. **导师修改学生学校名称**

   * 登录导师账号

   * 在学生列表中找到学生

   * 点击编辑学校按钮

   * 修改学校名称并保存

   * 验证数据库中 `school_name` 字段已更新

2. **学生端课程共享验证**

   * 学生A和学生B原本学校名称不同

   * 导师将两人学校名称改为相同

   * 学生A创建课程

   * 学生B登录后应该能看到学生A的课程

3. **权限验证**

   * 使用学生账号尝试修改其他学生学校名称

   * 验证操作被拒绝
