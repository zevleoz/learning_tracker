# 数据分析页面重写计划

## 一、问题分析

### 1.1 核心问题
- **CSS类名不匹配**：组件使用 `ma-` 前缀（如 `ma-panel`），但CSS中只有旧的 `mentor-analytics-` 前缀类
- **缺少响应式布局**：图表没有适配不同屏幕宽度
- **SVG尺寸问题**：部分图表使用固定尺寸，导致溢出
- **样式重复**：CSS中有大量重复定义的旧样式

### 1.2 当前组件结构
```
MentorAnalyticsPage
├── StudentOverviewCard (全宽)
├── SubjectRadarChart (全宽)
├── SubjectComparisonMatrix (全宽)
├── ScoreDistributionChart + LearningHeatmap (2列)
├── LearningBehaviorAnalysis (全宽)
├── ScoreTrendChart (全宽)
├── EfficiencyTrendChart (全宽)
└── PainPointAnalysis (全宽)
```

## 二、解决方案

### 2.1 架构设计
- 使用BEM命名规范，前缀为 `ma-`（mentor analytics）
- 所有SVG使用 `viewBox` + `width: 100%` 实现响应式
- 采用弹性布局：全宽为主，仅部分图表并排显示
- 统一面板样式、字体大小、间距

### 2.2 布局方案
```
┌─────────────────────────────────────────────────────────────┐
│  学生概览卡片（全宽）                                        │
├─────────────────────────────────────────────────────────────┤

├─────────────────────────────────────────────────────────────┤
│  科目对比矩阵（全宽）                                        │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────────┐ ┌─────────────────┐                    │
│  │ 分数分布         │ │ 学习热力图       │                    │
│  └─────────────────┘ └─────────────────┘                    │

│  学习行为分析（全宽，内部2列布局）                            │

│  分数趋势（全宽）                                            │

│  学习效率趋势（全宽）                                        │

└─────────────────────────────────────────────────────────────┘
```

## 三、实施步骤

### 步骤1：更新组件代码
- 确保所有组件使用正确的 `ma-` 前缀类名
- 所有SVG使用 `viewBox` + `width: 100%`
- 移除所有固定宽度设置

### 步骤2：添加完整CSS样式
- 定义 `ma-container`, `ma-header`, `ma-content` 等容器样式
- 定义 `ma-panel` 面板基础样式
- 定义各组件的专用样式
- 添加响应式布局支持

### 步骤3：清理旧样式
- 删除 `mentor-analytics-` 前缀的所有样式
- 删除重复定义的样式

### 步骤4：验证测试
- 检查每个组件是否完整显示
- 验证文字无截断
- 确认无SVG溢出
- 测试响应式布局

| `src/pages/MentorAnalytics.jsx` | 修改 | 更新组件代码，确保类名正确 |

## 五、预期效果

重写后的数据页面将：
- 所有组件完整显示，无文字截断
- 图表自适应容器宽度，无溢出
- CSS样式清晰，无重复定义
- 布局结构合理，层次分明
- 代码易于维护和扩展
