# 导师复盘仪表盘大改版 — Week Review Dashboard Overhaul

## 一、设计理念（青少年学习力导师视角）

用户提供的 7 个维度 SOP 构成了"一表人才"的核心教育逻辑。新仪表盘不是简单的图表堆叠，而是**从教育诊断角度出发的信息架构**：

| 维度        | SOP 要点                | 数据来源                           | 一眼可见的关键指标  |
| --------- | --------------------- | ------------------------------ | ---------- |
| 01 学习参与度  | 是否愿意记录、整理 Syllabus、复盘 | 有记录的天数 / 总天数                   | 活跃天数比      |
| 02 学习总时长  | 有效学习时间是否足够            | `duration_minutes` 汇总          | 总时长 + 日均   |
| 03 学科时间分配 | 时间分配本身就是教育决策          | 按 `course.name` 分组             | 集中度 / 偏科指数 |
| 04 复习占比   | 学习-复习-练习循环            | `category` 1/2/3 占比            | 三类比例       |
| 05 练习质量   | 不只是"做了多久"             | `category=3` + `score`         | 练习均分       |
| 06 自主学习比例 | Student Agency        | `form` 是否自主                    | 自主占比       |
| 07 过程反馈密度 | 反馈越及时调整成本越低           | 有 `score` 或 `self_rating` 的记录数 | 反馈/天       |

**第 8 个隐性维度 — 反推教育问题**：当 02-06 都达标但成绩仍低，提示问题在教学环境而非学生。这个逻辑需要写进仪表盘的"诊断结论"中。

### 日卡片内部信息密度设计

每个日卡片包含 5 层信息，用视觉层次区分优先级：

| 层级     | 内容            | 视觉形式             | 为什么这样设计  |
| ------ | ------------- | ---------------- | -------- |
| L1（最大） | 当日总时长         | 24px 粗体数字 + 颜色深浅 | 一眼看到投入量  |
| L2（次大） | 学/复/练比例       | 3 色堆叠条（蓝/橙/绿）    | 一眼看到循环结构 |
| L3（中等） | 前 2-3 科目 + 时间 | 小字行 "科目 缩写 + 分钟" | 看到分配去向   |
| L4（小）  | 自主比例          | 半圆图标 ◐/● + 百分比   | 看到自主性    |
| L5（最小） | 当日评分          | 彩色标签 B+ 85       | 看到产出质量   |

无记录的日子：灰色虚线边框 + "—" — 不隐藏空日子，让导师看到"哪天没学"本身就是参与度信号。

### 多周视图

当选择"过去 4 周"时：

* 周历网格显示 4 行，每行一周（日历样式）

* 维度总览汇总整个 4 周的数据

* 深度分析面板中的趋势图展示 4 周变化

### 移动端布局

* 周历：7 行竖排（每行一天），内容同桌面但更紧凑

* 维度总览：2 列网格

* 深度面板：堆叠展开

## 四、教育诊断结论逻辑（第 8 隐性维度）

仪表盘底部"教育诊断结论"面板，根据 7 维度数据交叉推断：

```
if 总时长充足 && 复习占比合理 && 练习质量达标 && 自主比例合理:
    if 某科均分仍长期 < 70:
        → 诊断："该生学习行为无明显缺陷，[科目] 长期低分可能源于教学环境"
        → 建议："建议检查课堂教学完整度 / 教师反馈及时性 / 课程难度匹配"

if 自主比例 < 30%:
    → 诊断："高度依赖外部驱动，自主性不足"
    → 建议："逐步引导自主复盘、自主寻找知识缺口"

if 复习占比 < 15%:
    → 诊断："学习-复习-练习循环断裂"
    → 建议："建立规律复习节奏，避免考前突击"

if 偏科指数 > 60%（前 1 科占总时长 60%+）:
    → 诊断："时间分配严重失衡"
    → 建议："调整分配，向薄弱科目倾斜"
```

### 新组件 API 设计

#### `WeekReviewDashboard`（主入口）

```jsx
<WeekReviewDashboard
  sessions={sessions}      // 已映射的 session 数组
  student={picked}         // 学生信息 { id, full_name, school_name }
/>
```

内部状态管理：选中的时间段、展开的面板。

#### `WeekGrid`（周历网格）

```jsx
<WeekGrid
  sessions={weekSessions}  // 过滤到当前周的 sessions
  weekStart={date}         // 周一日期
  onDayClick={fn}          // 点击某天展开详情
/>
```

#### `DimensionStrip`（维度摘要条）

```jsx
<DimensionStrip
  sessions={periodSessions}  // 整个时段的 sessions
  period={{ start, end }}    // 时段范围
/>
```

### 数据查询更新（Mentor.jsx L268-271）

当前查询：

```sql
id, session_date, duration_minutes, category, form, eval_type,
score, course_id, course:course_id(name, subject)
```

更新为（加 `start_time`, `self_rating`, `grade_label`）：

```sql
id, session_date, start_time, duration_minutes, category, form, eval_type,
score, self_rating, grade_label, course_id, course:course_id(name, subject)
```


### 遗留组件保留策略

在 `Mentor.jsx` 顶部添加 feature flag：

```jsx
// ═══════════════════════════════════════════════════════════
// FEATURE FLAG: 设为 true 可切换回旧版仪表盘
// 旧版组件保留在 SharedDashboard.jsx (ReviewDashboard) 和
// MentorAnalytics.jsx (MentorAnalyticsPage)，均标记为 @legacy
// ═══════════════════════════════════════════════════════════
const USE_LEGACY_DASHBOARD = false;
```

在渲染处：

```jsx
{USE_LEGACY_DASHBOARD ? (
  <ReviewDashboard sessions={sessions} />
) : (
  <WeekReviewDashboard sessions={sessions} student={picked} />
)}
```

在 `SharedDashboard.jsx` 和 `MentorAnalytics.jsx` 每个导出组件上方加：

```jsx
/**
 * @legacy v1 旧版复盘仪表盘 — 2026-08 版本
 * @description [组件功能描述]
 * @status 已被 WeekReviewDashboard 替代，代码保留以备复用
 * @reEnable 在 Mentor.jsx 中将 USE_LEGACY_DASHBOARD 设为 true
 */
```

## 七、假设与决策

| 决策点      | 选择                              | 理由                   |
| -------- | ------------------------------- | -------------------- |
| 多周视图方式   | 多行日历（每行一周）                      | 保留时间上下文，能看到跨周规律      |
| 深度面板默认状态 | 折叠                              | 保持首屏简洁，避免信息过载        |
| 旧版保留方式   | JSDoc @legacy 标签 + feature flag | 不移动文件，零破坏性，一键切换      |
| 时段选择粒度   | 周/双周/4 周/月                      | 对应导师常见复盘周期           |
| 空日显示方式   | 灰色虚线 + "—"                      | "没学"本身就是参与度信号        |
| 诊断结论     | 规则引擎（if-else）                   | 第一版用确定性规则，后续可迭代为评分模型 |
