# 数据分析页面图表规划文档

> 本文档列出数据分析页面中所有图表的详细信息，可直接编辑修改。

## 1. 学生概览卡片 (StudentOverviewCard)

### 位置

页面顶部全宽，紧贴页面header下方

### 坐标布局

| 区域 | 位置 | 内容 |
| --- | --- | --- |
| 左侧 | 左对齐 | 学生头像 + 姓名 + 学校 |
| 右侧 | 右对齐，水平排列 | 6个统计指标卡片 |

### 显示数据

| 指标 | 数据来源 | 格式 |
| --- | --- | --- |
| 学习记录数 | sessions.length | 数字 |
| 累计时长 | sum(sessions.duration_minutes) | 数字（小时/分钟） |
| 平均分数 | avg(eval_type=2的score) | 数字 + 字母等级 |
| 自主学习率 | 自主学习时长/总时长 | 百分比 |
| 学习时长 | category=1的总时长 | 数字（小时/分钟） |
| 练习时长 | category=3的总时长 | 数字（小时/分钟） |

### 价值

* **核心价值**：页面"仪表盘"，一眼看到学生核心指标
* 建立整体认知，快速判断学生学习概况
* 作为后续深度分析的入口，帮助老师决定从哪个维度切入

### 优化建议（可编辑）

* [ ] 颜色对比度可以更高，增强视觉层次
* [ ] 添加进度条显示自主学习率，更直观

## 2. 科目投入产出对比图 (SubjectBarChart)

### 位置

学生概览卡片下方，全宽

### 坐标布局

| 元素 | 坐标 | 说明 |
| --- | --- | --- |
| X轴 | 水平方向，底部 | 各科目名称（数学、英语、物理等） |
| Y轴 | 垂直方向，左侧 | 0-100分数/时长评分 |
| 紫色柱状 | 每个科目左侧 | 学习时长评分（归一化到0-100） |
| 绿色柱状 | 每个科目右侧 | 分数表现（原始0-100） |
| 底部数值 | 图表下方，水平排列 | 每个科目的详细数据（时长+分数+字母等级） |

### 显示数据

| 元素 | 数据内容 | 归一化方式 |
| --- | --- | --- |
| X轴 | 各科目名称 | - |
| Y轴 | 0-100分 | - |
| 紫色柱状 | 各科目学习时长 | min(100, duration/max_duration*100) |
| 绿色柱状 | 各科目平均分数 | 原始分数（0-100） |

### 价值

* **核心价值**：对比"投入"（学习时长）与"产出"（分数）是否匹配
* **投入多但分数低** → 学习方法需调整（如物理投入多但分数低）
* **投入少但分数高** → 高效学习，值得借鉴（如历史投入少但分数高）
* 快速识别哪个科目投入产出比最优/最差

### 优化建议（可编辑）

* [ ] 添加数值标签在柱状图顶部，更易读
* [ ] 可以添加趋势线或参考线，显示平均水平

## 3. 科目对比矩阵 (SubjectComparisonMatrix)

### 位置

科目投入产出对比图下方，全宽

### 坐标布局

| 列名 | 位置 | 内容 |
| --- | --- | --- |
| 科目名称 | 第1列 | 科目名，可排序 |
| 学习时长 | 第2列 | 分色进度条（学习/复习/练习）+ 总时长文字 |
| 占比 | 第3列 | 进度条 + 百分比数字 |
| 客观评价 | 第4列 | 数字分数 + 字母等级 + 颜色编码 |
| 主观评价 | 第5列 | 优秀/良好/一般/薄弱（文字+背景色） |
| 自主率 | 第6列 | 百分比数字 |

### 显示数据

| 列名 | 数据内容 | 格式 |
| --- | --- | --- |
| 科目名称 | 科目名 | 文字 |
| 学习时长 | 该科目学/复/练时长 | 分色进度条（紫色=学习，紫色偏粉=复习，粉色=练习） |
| 占比 | 该科目时长占总时长的百分比 | 进度条 + 百分比 |
| 客观评价 | 该科目平均分 | letter grade + 颜色编码（绿=好，黄=中，红=差） |
| 主观评价 | 优秀/良好/一般/薄弱（平均） | 文字 + 背景色 |
| 自主率 | 该科目自主学习比例 | 百分比 |

### 价值

* **核心价值**：详细的科目横向对比表格，支持排序
* 快速找出薄弱科目（按分数排序）
* 快速找出自主率低的科目（按自主率排序）
* 了解各科目学习类型分配（学习/复习/练习的比例）

### 优化建议（可编辑）

* [ ] 添加科目筛选功能
* [ ] 可以高亮显示需要关注的科目（如分数<70或自主率<50%）

## 4. 学习投入日历 (LearningHeatmap)

### 位置

科目对比矩阵下方，2列布局的左侧

### 坐标布局

| 元素 | 位置 | 内容 |
| --- | --- | --- |
| 统计摘要 | 上方 | 总学习时长、活跃天数（左右并排） |
| 星期标题 | 日历上方 | 一、二、三、四、五、六、日（水平排列） |
| 日期网格 | 中间 | 5周 × 7天的格子矩阵 |
| 颜色图例 | 下方 | 少→多的颜色渐变 |

### 显示数据

| 元素 | 数据内容 | 格式 |
| --- | --- | --- |
| 横向网格 | 35天（5周） | 日期 |
| 格子颜色 | 当天学习时长 | 颜色编码（白色=无，绿色越深=时长越长） |
| 顶部统计 | 总学习时长、活跃天数 | 数字 |
| 底部图例 | 颜色深浅对应学习量 | 色块 + 文字 |

### 价值

* **核心价值**：查看学习规律性和持续性
* 判断是否每天坚持学习（格子是否连续有颜色）
* 识别学习低谷期（大面积白色区域）
* 判断最近是否有中断（右侧是否连续）

### 优化建议（可编辑）

* [ ] 添加悬停显示具体日期和时长
* [ ] 可以选择查看不同时间段（如最近4周、最近8周）

## 5. 学习行为分析 (LearningBehaviorAnalysis)

### 位置

学习投入日历下方，全宽

### 坐标布局

| 区域 | 位置 | 内容 |
| --- | --- | --- |
| 左侧 | 左半部分 | 学习类型分配（横向进度条） |
| 右侧 | 右半部分 | 学习来源分配（环形图） |
| 底部 | 全宽，下方 | 4个统计卡片（总时长、学习次数、平均时长、自主率） |

### 显示数据

| 元素 | 数据内容 | 格式 |
| --- | --- | --- |
| 学习类型分配（左侧） | 学习/复习/练习的时长和占比 | 横向进度条 |
| 学习来源分配（右侧） | 自主学习/校外辅导的时长和占比 | 环形图 |
| 底部统计卡片 | 总时长、学习次数、平均时长、自主率 | 数字卡片 |

### 价值

* **核心价值**：分析学习结构和学生独立性
* 学习/复习/练习的比例是否健康（理想比例约4:3:3）
* 判断学生独立性：自主学习率高低反映学生主动性
* 快速识别是否过度依赖校外辅导

### 优化建议（可编辑）

* [ ] 添加理想比例参考线
* [ ] 添加月度对比，显示学习行为变化

## 6. 分数趋势 (ScoreTrendChart)

### 位置

学习行为分析下方，全宽

### 坐标布局

| 元素 | 坐标 | 说明 |
| --- | --- | --- |
| X轴 | 水平方向，底部 | 时间（日期） |
| Y轴 | 垂直方向，左侧 | 分数（0-100） |
| 蓝色折线 | X-Y平面 | 各次评分的变化趋势 |
| 60分及格线 | Y=60 | 橙色虚线 |
| 80分优秀线 | Y=80 | 橙色虚线 |
| 数据点 | 折线上 | 圆形标记 + 分数 + 字母等级 |
| 筛选按钮 | 图表上方右侧 | 最近5次/10次切换 |

### 显示数据

| 元素 | 数据内容 | 格式 |
| --- | --- | --- |
| X轴 | 时间（日期） | 日期 |
| Y轴 | 分数（0-100） | 数字 |
| 蓝色折线 | 各次评分的变化 | 折线 |
| 橙色虚线 | 及格线和优秀线 | 虚线 |
| 数据点 | 每次评分的分数和等级 | 圆形 + 数字 + 字母 |

### 价值

* **核心价值**：追踪分数变化趋势，判断进步或退步
* 识别上升趋势（折线向右上方）
* 识别下降趋势（折线向右下方）
* 判断是否接近及格线或优秀线
* 通过筛选查看短期（5次）或中期（10次）变化

### 优化建议（可编辑）

* [ ] 添加科目筛选，查看特定科目趋势
* [ ] 添加趋势线预测

## 7. 学习效率趋势 (EfficiencyTrendChart)

### 位置

分数趋势下方，全宽

### 坐标布局

| 元素 | 坐标 | 说明 |
| --- | --- | --- |
| X轴 | 水平方向，底部 | 日期（最近14天） |
| Y轴 | 垂直方向，左侧 | 分数（0-100） |
| 紫色柱状 | 底部向上 | 每天学习时长（归一化） |
| 绿色散点 | X-Y平面 | 当天的平均分数 |
| 橙色虚线 | Y=平均分 | 所有天数的平均分数参考线 |

### 显示数据

| 元素 | 数据内容 | 格式 |
| --- | --- | --- |
| X轴 | 日期（最近14天） | 日期 |
| 柱状图（紫色） | 每天学习时长 | 柱状 |
| 散点（绿色） | 当天的平均分数 | 散点 |
| 橙色虚线 | 所有天数的平均分数 | 虚线 |

### 价值

* **核心价值**：分析"学习投入"与"分数产出"的关系
* **投入高但分数低** → 效率低，需调整方法
* **投入适中但分数高** → 效率高，值得保持
* 识别效率波动较大的日期
* 判断是否存在"无效学习"（时长很长但分数不高）

### 优化建议（可编辑）

* [ ] 添加效率评分公式说明
* [ ] 可以计算并显示效率指数趋势

## 8. 痛点诊断与建议 (PainPointAnalysis)

### 位置

学习效率趋势下方，全宽（页面底部）

### 坐标布局

| 元素 | 位置 | 内容 |
| --- | --- | --- |
| 问题卡片 | 垂直排列 | 每个问题一张卡片 |
| 优先级标记 | 卡片左侧 | 数字序号（1=最高优先级） |
| 问题标题 | 卡片上方 | 问题名称（如"物理分数偏低"） |
| 问题描述 | 标题下方 | 问题的详细说明 |
| 当前值 | 卡片右侧 | 问题相关的数值 |
| 改进建议 | 描述下方 | 2-3条可操作的建议 |

### 显示数据

| 元素 | 数据内容 | 格式 |
| --- | --- | --- |
| 问题标题 | 自动识别的问题 | 文字 |
| 当前值 | 问题相关的数值 | 数字 |
| 问题描述 | 问题的详细说明 | 文字 |
| 改进建议 | 2-3条可操作的建议 | 列表 |

### 触发条件

| 问题类型 | 触发条件 |
| --- | --- |
| 学习频率不足 | 最近30天活跃天数 < 10天 |
| 科目分数偏低 | 某科目平均分 < 70分 |
| 自主学习率偏低 | 自主学习率 < 50% |

### 价值

* **核心价值**：自动生成学习诊断报告，给出可操作的建议
* 节省老师分析时间，直接提供行动方案
* 按优先级排序，帮助老师聚焦最重要的问题
* 提供具体的改进措施，而非泛泛而谈

### 优化建议（可编辑）

* [ ] 添加更多触发条件（如学习时长不足、分数波动大）
* [ ] 添加建议执行状态追踪
