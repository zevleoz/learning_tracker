# 导师端数据分析页面优化计划

## 一、问题分析

当前数据分析页面存在以下问题：
1. **数据不足**：jeff@example.com 账号缺乏代表性学习数据，图表显示为空或数据不准确
2. **字母等级显示**：使用字母等级（A/B/C/D/F）不够直观，用户要求使用原始数字分数
3. **图表细节不足**：现有图表不够精细，难以看清细节
4. **内容单一**：只有一页内容，需要扩展更多分析维度

## 二、改进方案

### 2.1 添加代表性假数据

为 jeff@example.com 创建完整的学习数据，包括：
- 5个科目（数学、英语、物理、化学、历史）
- 30天学习记录
- 多种学习类型（学习、复习、练习）
- 多种学习形式（自主学习、校外辅导）
- 客观分数（0-100）

### 2.2 移除字母等级，使用原始数字

- 删除 `avgScoreToGrade` 函数
- 所有分数显示改为直接显示数字（保留1位小数）
- 使用颜色渐变表示分数高低（绿色=高分，红色=低分）

### 2.3 扩展图表内容（超过1页）

新增以下图表组件：
1. **学习投入热力图**：按日期和时段展示学习分布
2. **分数分布直方图**：展示各科目分数分布情况
3. **效率趋势图**：展示学习效率随时间变化
4. **科目对比横向条形图**：更直观的科目对比
5. **进步分析指标卡**：展示进步幅度和趋势

### 2.4 优化现有图表细节

- 雷达图：增加数据标签，优化颜色对比度
- 矩阵表格：增加更多数据列，优化行高和间距
- 行为分析：优化时间轴显示，增加更多统计指标
- 趋势图：增加数据点标签，优化坐标轴
