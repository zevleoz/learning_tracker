已经定下来的

  • ✓ 复制就算已发。不再有单独的「已发」按钮，复制后这条折叠成一行，可撤销。
  • ✓ 「过几天再说」到期后按最新的记录重新写一条，不是把旧的放回来。期间学生记了，提醒就自动撤掉。
  • ✓ 同一个学生的两次提醒至少隔 3 天。「过几天再说」只给 3 天后 / 5 天后 / 7 天后三个选项；表扬不受这个限制。
  • ✓ 管理员能做导师能做的一切。两个人都能处理同一条消息，所以已发的那行会写「谁、几点发的」，避免学生收到两遍。以后学生分配给某位导师后，管理员对这些学生的消息只能看、不能处理（这版先不做）。
  • ✓ 不再用「新生」。注册 30 天内统一叫「首月」，写成「首月 · 第 13 天」；之后叫「每周看」。现有代码里的「新生昨天没填」「新生 = 注册 30 天内」等文字都要跟着改。

AI 只能看到学生填的记录

  • 看得到：科目 / 章节 / 单元、学习·复习·练习、时长、自评、练习的实测、备注。看不到作业、题目和试卷本身。
  • 所以只说记录里有的事：备注原话可以引用；不说「写得清楚」「弄懂了」「很认真」，不编备注里没写的动作和数量，不推因果，不说「很稳」「扎实」。
  • 看全局：代码先把一段时间的规律算出来（同一章学了又复习、实测从 B- 到 B+、第一次记某科），AI 挑最能说明情况的一件说。
  • 最多问一个问题，要具体、一句话能答。生成后由代码检查等第、数字、引号里的原话是否都能在记录里找到；对不上的会提示导师发之前看一眼。

建议：「今天」「全部学生」做成学生管理里的两个标签，学生详情做成单独一页

  1. 侧栏不加东西。上次在侧栏加「今日」被否了，这次两个视图都放在「学生管理」里面，用页内标签切换。
  2. 「今天」是做事的地方：要发的消息 + 这周谁记了谁没记。打开导师台默认落在这里。
  3. 「全部学生」是管名单的地方：按顾问（备注名括号里的 Angela / Jason）分组，邀请、连接状态、学校筛选都在这里。现在首页上的这些工具挪过来，所以首页就不挤了。
  4. 顾问和导师是两回事。导师是登录账号（陈老师、李老师）；顾问是备注名里写的名字，只用来分组，不是账号。两个标签右上角的「顾问」下拉是同一个筛选。管理员视图里另外多一列「导师」。
  5. 学生详情做成单独一页，不再从右侧滑出。要放的东西变多了：今天的消息、四周的填写日历、发过的消息（提醒间隔要看得到）、最近的记录。侧滑面板放不下，也没法用链接直接打开、没法返回。单独一页带「← 返回」，回到点进来的那个标签。
