# 数据展示改进计划

## 一、当前数据展示分析

### 学生端 Review 页面

目前展示的4个区块：

1. **学习总览（HeroBlock）**：本周总时长、日均、工作日/周末对比
2. **月度趋势（MonthlyBarsBlock）**：6个月柱状图
3. **科目投入（SubjectMatrixBlock）**：各科目学习·复习·练习分解
4. **客观评估（ObjectiveScoresBlock）**：各科目平均分 + Letter Grade

### 老师端学生数据查看

* 通过 `ReviewDashboard` 组件复用学生端的4个区块

* 老师选择学生后，在右侧面板显示数据

## 二、存在的问题

| 问题         | 影响            | 优先级 |
| ---------- | ------------- | --- |
| 缺少学习连续性指标  | 无法评估学习习惯养成    | 高   |
| 缺少自我评估汇总   | 主观评价数据未被利用    | 中   |
| 缺少学习效率指标   | 无法评估投入产出比     | 高   |
| 时间范围固定     | 用户无法查看不同时间段数据 | 中   |
| 老师端缺少班级概览  | 无法了解整体班级表现    | 高   |
| 老师端缺少多学生对比 | 无法进行横向比较      | 中   |
| 学习建议不够具体   | 建议偏笼统，缺乏针对性   | 中   |

## 三、改进方案

### 1. 学生端增强

**1.1 新增学习连续性指标**

* 连续学习天数（当前 streak）

* 本周学习天数占比

* 显示 streak 图标和颜色变化

**1.2 新增自我评估汇总**

* 各科目主观评价平均分

* 自评 vs 客观分数对比

* 掌握程度分布（雷达图或进度条）

**1.3 新增学习效率指标**

* 投入时间 vs 成绩变化趋势

* 单位时间学习量指标

* 效率评分（A/B/C/D）

**1.4 时间范围选择器**

* 本周 / 本月 / 近3个月 / 全部

* 自定义日期范围

### 2. 老师端增强

<br />

**2.2 学生对比功能**

* 选择2-3个学生进行对比

* 对比维度：学习时长、成绩、效率

**2.3 老师视角分析工具**

* 学生进步趋势追踪

* 薄弱科目预警

* 学习行为模式识别

### 3. 共同改进

**3.1 改进数据可视化**

* 添加趋势箭头（上升/下降）

* 添加同比/环比对比

* 使用颜色编码表示状态（好/中/差）

**3.2 增强学习建议**

* 基于历史数据的个性化建议

* 结合科目特点的针对性建议

* 行动导向的建议（而非描述性）

## 四、实施步骤

* 汇总主观评价数据

### 步骤 4：老师端学生对比

* 添加学生多选功能

* 创建对比面板组件

### 步骤 5：增强学习建议

* 修改 `SuggestionsBlock`，添加更具体的建议逻辑

## 六、预期效果

* 学生能更全面了解自己的学习情况（连续性、效率、自评）

* 老师能了解班级整体表现并进行学生对比

* 学习建议更具针对性和可操作性

* 用户可自定义查看不同时间段的数据
