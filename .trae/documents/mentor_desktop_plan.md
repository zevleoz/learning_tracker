# 老师端页面桌面端优化计划

## 一、现状分析

当前 Mentor.jsx 的问题：
- 最大宽度限制在 900px，浪费桌面空间
- 使用移动端风格的玻璃卡片布局
- 学生列表是简单的纵向排列
- Review 查看需要下拉选择，体验不佳
- 缺少专业的仪表板布局

## 二、设计目标

打造专业的老师端仪表板：
- 三栏布局：侧边栏 + 学生列表 + 详情面板
- 学生列表使用表格形式，支持筛选和搜索
- Review 数据实时展示，无需切换
- 专业的企业级视觉风格
- 响应式设计，移动端保持现有布局

## 三、实施步骤

### 步骤 1：创建桌面端专用布局组件

创建 `src/components/MentorLayout.jsx`，包含：
- 侧边栏导航（学生管理、数据分析、系统设置）
- 顶部工具栏（搜索、筛选、导出）
- 主内容区域（可切换视图）

### 步骤 2：重构 Mentor.jsx

重新设计桌面端 UI：
- 学生列表改为数据表格
- 添加搜索和筛选功能
- 点击学生自动打开详情面板
- Review Dashboard 优化为桌面端视图
- 添加更多统计指标

### 步骤 3：更新 CSS 样式

在 index.css 中添加：
- 桌面端仪表板样式
- 数据表格样式
- 侧边栏样式
- 详情面板样式

### 步骤 4：响应式适配

确保：
- 桌面端（>768px）：三栏布局
- 平板端（768px-1024px）：两栏布局
- 移动端（<768px）：原有布局

## 四、文件修改清单

| 文件 | 修改类型 | 说明 |
|---|---|---|
| `src/pages/Mentor.jsx` | 重写 | 桌面端 UI 重构 |
| `src/components/MentorLayout.jsx` | 新建 | 老师端专用布局组件 |
| `src/index.css` | 修改 | 添加桌面端仪表板样式 |
| `src/components/Layout.jsx` | 修改 | 根据角色选择布局 |

## 五、风险评估

| 风险 | 概率 | 影响 | 缓解措施 |
|---|---|---|---|
| 布局冲突 | 中 | 页面显示异常 | 先开发桌面端专用组件 |
| 学生列表性能 | 低 | 大量学生时卡顿 | 添加分页和虚拟滚动 |
| 响应式适配 | 中 | 不同屏幕尺寸显示问题 | 多断点测试 |

## 六、预期效果

- 专业的三栏仪表板布局
- 高效的学生管理体验
- 清晰的数据可视化
- 流畅的交互体验
