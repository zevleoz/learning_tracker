# 老师端数据分析页面优化计划

## 一、修复科目汇总卡片

### 问题描述
当前迷你堆叠条使用百分比显示（学习/复习/练习各占总时长的百分比），用户要求总时长决定条的长度。

### 修改方案
将堆叠条改为：
- 每个科目条的总长度 = (该科目总时长 / 最大总时长) * 100%
- 条内各部分按比例分配（学习/复习/练习）
- 最长的科目条占满整个宽度，其他按比例缩短

### 文件
- `src/pages/Review.jsx` - SubjectSummaryBlock 组件

## 二、老师端数据分析页面设计

### 设计理念
参考麦肯锡风格：
- 清晰的层次结构
- 充分利用网页宽度（三栏布局）
- 数据驱动的可视化
- 简洁的配色方案
- 高信息密度

### 业务定位
- **不是学校，是留学服务机构**
- **核心目标**：帮助学生找到学习痛点，分科目分析哪里做得不好
- **学生端**：类似 Calorie Tracker，简单记录
- **老师端**：全面透彻的数据分析，帮助诊断问题

### 页面结构

#### 1. 学生概览卡片（顶部）
| 指标 | 说明 |
|------|------|
| 学生姓名 | 当前查看的学生 |
| 总学习时长 | 最近7天/30天总时长 |
| 日均学习时长 | 平均每天学习时间 |
| 科目数量 | 涉及的科目数 |
| 平均分数 | 客观评估平均分 |
| 效率指数 | 分数/学习时长 |

#### 2. 科目雷达图（左侧）
- 多维度展示各科目表现：
  - 学习时长
  - 复习时长
  - 练习时长
  - 客观分数
  - 自主学习率
- 帮助识别强弱科目

#### 3. 科目对比矩阵（中间）
- 表格形式，每行一个科目：
  - 学习时长（条形图）
  - 分数等级（Letter Grade）
  - 自主占比（颜色编码）
  - 行为分布（迷你堆叠条）
  - 学习趋势（最近7天变化）
- 可排序，方便对比

#### 4. 学习行为分析（右侧）
- 学习/复习/练习时间分布
- 每日学习规律（时间轴）
- 自主学习 vs 校外辅导对比
- 效率分析（投入产出比）

#### 5. 分数趋势分析（底部全宽）
- 各科目分数随时间变化
- 学习时长与分数的相关性
- 预测趋势线

#### 6. 痛点诊断与建议（底部）
- 自动识别学习痛点：
  - 学习时间不足的科目
  - 分数偏低的科目
  - 自主学习率低的科目
  - 学习时间与分数不匹配的科目
- 针对每个痛点给出具体建议

- `src/pages/Mentor.jsx` - 添加数据分析页面内容
- `src/index.css` - 添加数据分析页面样式

## 四、风险与注意事项

### 数据量问题
- 如果学习记录较多（2000+），图表渲染可能较慢
- 解决方案：限制查询时间范围（最近3个月）

### 性能问题
- 大量数据的图表渲染可能影响性能
- 解决方案：使用 SVG 而非 Canvas，优化渲染逻辑

### RLS 策略
- 确保老师只能看到已连接学生的数据
- 已通过之前的 RLS 策略修复

### 可视化清晰度
- 避免信息过载，保持每个图表的单一目的
- 使用颜色编码和层次结构区分不同维度
